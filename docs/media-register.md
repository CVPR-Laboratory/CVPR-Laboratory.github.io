# Media Management

`media-register.csv` is generated by `python scripts/optimize-images.py`. It records every original file under `images/` and `assets/images/`, dimensions, byte size, optimized path and current authorization status.

- Keep original assets as the compatibility fallback.
- The site prefers generated WebP through `<picture>` and falls back to PNG/JPEG.
- Do not overwrite portraits or logos with unrelated images.
- New media must have a traceable provider and publication permission before its status is changed from pending.
- Remove embedded location or personal metadata from newly supplied photographs when it is unnecessary.
- Run the generator after adding, replacing or deleting an image; commit the CSV and generated WebP together.

The current register describes assets already present in the accepted site delivery. It is an inventory, not a transfer of copyright.
