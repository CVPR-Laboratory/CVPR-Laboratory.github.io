# Test Report

Release candidate reviewed: 2026-08-17.

## Automated checks

- JavaScript syntax: every file under `assets/js/` checked with `node --check`.
- Static integrity: titles, descriptions, canonical/Open Graph metadata, exact-case local paths, structured-data fields, sitemap URLs and required documents checked by `scripts/check-static.mjs`.
- Media: all originals inventoried and raster WebP variants generated by `scripts/optimize-images.py`.

## Browser matrix

Nine pages were exercised at 360 px and 1440 px, in Chinese and English, dark and light themes. The matrix included invalid profile/article IDs. Expected results: HTTP 200 for valid assets, one H1 per page, no horizontal overflow, correct language/theme persistence and a friendly missing-record state. The three broken news image paths found in the first pass were replaced with existing repository images.

Before each deployment, repeat the smoke test for `index.html`, navigation, member profile, news article, copy-email action, language/theme controls and a 404 URL. Record any environment-specific failure in `known-issues.md`.
