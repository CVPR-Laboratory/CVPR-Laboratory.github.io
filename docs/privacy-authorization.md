# Privacy And Authorization

Public content must be limited to information supplied for the laboratory website or already approved in the current delivery. The site does not collect form submissions, analytics identifiers or cookies. Theme and language preferences are stored locally in the visitor's browser.

Member email, telephone, portrait, CV, biography and destination information require authorization from the member or laboratory maintainer. Unknown fields stay unpublished. Contact details in `contact.js`, and Developer B's current member/news content, are treated as reviewed for this release following the repository owner's instruction dated 2026-08-17.

For removal or correction requests, update the structured data, regenerate artifacts, record the change in Git, and redeploy. Never place private source spreadsheets, identity documents, unpublished CVs or access credentials in this public repository.
